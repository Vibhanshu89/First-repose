# SHL / AMCAT Online Assessment Platform Simulator

A responsive, interactive front-end simulation of the online assessment platform (SHL / AMCAT), featuring a real-time exam countdown timer, candidate profile drawer, modular question navigation palette, multiple exam sections, and responsive UI.

## 🚀 Features

- **Realistic Assessment Interface**: Accurate replica of candidate test console and simulated browser window.
- **Section Switching**: Aptitude, Logical Ability, Verbal, and Technical Assessment questions.
- **Question Palette**: Live visual tracking of questions (Current, Answered, Marked for Review, and Unvisited).
- **Proctoring / Instructions**: Integrated candidate instructions modal and drawer details.
- **Pure Frontend**: Built with pure HTML5, CSS3, and JavaScript — no build step or backend required!

## 🌐 Live Deployment Options

Since this project consists of static files (`index.html`, `style.css`, `app.js`, `questions.js`), you can deploy it in seconds:

### Option 1: GitHub Pages (Recommended)
1. Go to repository **Settings** on GitHub.
2. Click on **Pages** in the left sidebar.
3. Under **Build and deployment > Source**, select **Deploy from a branch**.
4. Choose Branch: `main` and Folder: `/ (root)`.
5. Click **Save**. Within 1–2 minutes, your live site will be accessible at:
   `https://vibhanshu89.github.io/First-repose/`

### Option 2: Vercel
1. Log in to [vercel.com](https://vercel.com).
2. Click **Add New Project** and import `Vibhanshu89/First-repose`.
3. Keep default settings and click **Deploy**.

### Option 3: Netlify
1. Log in to [netlify.com](https://netlify.com).
2. Click **Add new site > Import an existing project > GitHub**.
3. Select `Vibhanshu89/First-repose` and deploy.
